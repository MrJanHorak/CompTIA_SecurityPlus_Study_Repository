## How to Use

1. Attempt each question without notes.
2. Score your confidence (1-5) before checking rationale.
3. Link misses back to rows in the objective coverage matrix.
4. Review [Answer Key and Distractor Analysis](Answer_Key_and_Distractor_Analysis.md).

## Depth Standard

- Each domain bank contains 30 scenario questions.
- Use two timed blocks of 15 questions to simulate pressure.
