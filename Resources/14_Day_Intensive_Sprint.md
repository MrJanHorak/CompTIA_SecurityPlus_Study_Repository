# 14-Day Intensive Sprint (Experienced Learners)

## Goal

Use this sprint only if you already have baseline security knowledge and need focused exam readiness.

## Daily Plan

| Day   | Focus                                      |
| ----- | ------------------------------------------ |
| 1-3   | Domain 4 intensive review (highest weight) |
| 4-5   | Domain 2 threat/vuln drills                |
| 6-7   | Mixed mock exams and analysis              |
| 8-9   | PBQ simulation sessions                    |
| 10-11 | Domain 3 architecture refresh              |
| 12    | Domain 5 governance and risk formulas      |
| 13    | Ports, acronyms, and weak-point blitz      |
| 14    | Final full mock and confidence review      |

## Minimum Readiness Check

- Three consecutive mock exam scores at 80% or higher
- Confident with NIST IR phases and triage flow
- Able to explain Zero Trust, IAM, and risk formulas from memory
