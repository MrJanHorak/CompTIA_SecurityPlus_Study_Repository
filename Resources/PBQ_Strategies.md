# PBQ Strategies for Security+ SY0-701

## Core PBQ Tactics

1. Read the objective and expected outcome first.
2. Identify high-impact constraints (time, access, business impact).
3. Apply least privilege and containment mindset by default.
4. Validate changes against the requested security outcome.
5. Move on quickly if stuck; return with remaining time.

## Common PBQ Archetypes

| Type                         | Typical Task                                 |
| ---------------------------- | -------------------------------------------- |
| Log analysis                 | Identify compromise indicators and next step |
| ACL/rule review              | Select least-permissive valid rule set       |
| Incident response            | Order response actions by lifecycle phase    |
| IAM configuration            | Apply role policy and MFA requirements       |
| Vulnerability prioritization | Rank remediation by risk and exposure        |

## Mistakes to Avoid

- Overly broad access rules
- Skipping validation of controls
- Choosing technically correct but operationally unsafe actions
