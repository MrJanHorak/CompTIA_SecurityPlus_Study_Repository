# Security+ Acronym and Terminology Glossary

Use this glossary for daily 10-minute recall drills.

## Core Security and Operations Acronyms

| Acronym | Meaning                                          | Exam Context                     |
| ------- | ------------------------------------------------ | -------------------------------- |
| AAA     | Authentication, Authorization, Accounting        | IAM and access control           |
| APT     | Advanced Persistent Threat                       | Threat actor behavior            |
| AV      | Antivirus or Asset Value (risk context)          | Endpoint defense or risk formula |
| CA      | Certificate Authority                            | PKI trust model                  |
| CASB    | Cloud Access Security Broker                     | Cloud control enforcement        |
| CRL     | Certificate Revocation List                      | Certificate validity             |
| CVE     | Common Vulnerabilities and Exposures             | Vulnerability tracking           |
| CVSS    | Common Vulnerability Scoring System              | Risk prioritization              |
| DLP     | Data Loss Prevention                             | Data protection                  |
| DNS     | Domain Name System                               | Network and log analysis         |
| EDR     | Endpoint Detection and Response                  | Detection and response           |
| GRC     | Governance, Risk, and Compliance                 | Program oversight                |
| HIDS    | Host-based Intrusion Detection System            | Endpoint detection               |
| IAM     | Identity and Access Management                   | AuthN/AuthZ controls             |
| IDS     | Intrusion Detection System                       | Monitoring stack                 |
| IPS     | Intrusion Prevention System                      | Inline blocking                  |
| IR      | Incident Response                                | Lifecycle and playbooks          |
| KPI     | Key Performance Indicator                        | Program measurement              |
| KRIs    | Key Risk Indicators                              | Risk tracking                    |
| MFA     | Multi-Factor Authentication                      | Identity hardening               |
| MTTR    | Mean Time To Respond/Recover                     | Operations metrics               |
| NDR     | Network Detection and Response                   | Traffic anomaly detection        |
| OCSP    | Online Certificate Status Protocol               | Certificate status checks        |
| PAM     | Privileged Access Management                     | Admin account controls           |
| PBQ     | Performance-Based Question                       | Exam question type               |
| PKI     | Public Key Infrastructure                        | Certificates and trust           |
| RPO     | Recovery Point Objective                         | Data loss tolerance              |
| RTO     | Recovery Time Objective                          | Outage tolerance                 |
| RBAC    | Role-Based Access Control                        | Authorization model              |
| SASE    | Secure Access Service Edge                       | Modern secure network access     |
| SDLC    | Software Development Life Cycle                  | App security                     |
| SIEM    | Security Information and Event Management        | Log aggregation and triage       |
| SLA     | Service Level Agreement                          | Contract and operations          |
| SOAR    | Security Orchestration, Automation, and Response | Automated workflows              |
| SOC     | Security Operations Center                       | Monitoring function              |
| TTP     | Tactics, Techniques, and Procedures              | Adversary behavior               |
| UEBA    | User and Entity Behavior Analytics               | Behavior analytics               |
| WAF     | Web Application Firewall                         | Layer 7 protection               |
| ZTNA    | Zero Trust Network Access                        | Context-aware remote access      |

## Suggested Recall Drill

1. Cover the Meaning column and define each acronym.
2. Cover the Acronym column and reverse-recall the acronym.
3. Explain one realistic scenario where the acronym appears.
