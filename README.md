> A structured, evidence-based study framework for the CompTIA Security+ SY0-701 certification exam.

---

## Purpose

This repository is designed to help students pass Security+ while also building practical, job-ready cybersecurity skills. The content is organized around the official SY0-701 domains and reinforced with:

- Active recall prompts
- Spaced repetition workflows
- Hands-on lab projects
- PBQ-focused study strategies

---

## Exam Overview

| Property               | Detail                                                                    |
| ---------------------- | ------------------------------------------------------------------------- |
| Exam Code              | SY0-701                                                                   |
| Number of Questions    | Maximum 90                                                                |
| Question Types         | Multiple choice and performance-based questions (PBQs)                    |
| Time Limit             | 90 minutes                                                                |
| Passing Score          | 750 (scale 100-900)                                                       |
| Recommended Experience | 2 years in security-focused IT administration (recommended, not required) |

### Domain Weighting

| Domain | Title                                     | Weight |
| ------ | ----------------------------------------- | ------ |
| 1.0    | General Security Concepts                 | 12%    |
| 2.0    | Threats, Vulnerabilities, and Mitigations | 22%    |
| 3.0    | Security Architecture                     | 18%    |
| 4.0    | Security Operations                       | 28%    |
| 5.0    | Security Program Management and Oversight | 20%    |

> Key insight: Domain 4.0 is the most heavily weighted and should receive the largest share of your study time.

## How to Use This Repository

1. Start with [Resources/Study_Strategies.md](Resources/Study_Strategies.md).
2. Study domains in order, but allocate extra time to Domain 2 and Domain 4.
3. After each study block, use one cheat sheet for rapid recall.
4. Build daily flashcard reps using [Resources/Flashcards/README.md](Resources/Flashcards/README.md).
5. Complete labs weekly to prepare for PBQs and interviews.
6. Run timed mixed-question sets each weekend.
