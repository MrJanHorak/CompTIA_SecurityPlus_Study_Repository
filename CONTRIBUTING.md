# Contributing to the CompTIA Security+ Study Repository

Thank you for helping improve this study resource for the SY0-701 exam.

---

## Ways to Contribute

- Fix incorrect, outdated, or unclear technical details
- Add missing objective coverage
- Improve examples, diagrams, and active recall questions
- Add practical labs and scenario walkthroughs
- Share study workflow improvements

---

## Guidelines

### Accuracy

All technical content should align with the current CompTIA Security+ SY0-701 objectives.

If you reference changes from SY0-601, label them clearly:

```text
> SY0-601 Note: Previous objective focus was X. SY0-701 now emphasizes Y.
```

### Formatting

- Use Markdown
- Keep heading hierarchy consistent (H1 title, H2 sections, H3 sub-sections)
- Use tables for quick-reference data
- Use fenced code blocks where commands or pseudo-logs are shown
- End domain content files with an Active Recall Questions section

### Scope

- Do not include exam dumps or leaked questions
- Do not include copyrighted premium material
- Keep examples educational and ethical
- Avoid vendor lock-in unless the concept is exam-relevant

---

## Pull Request Process

1. Fork the repository.
2. Create a branch such as `fix/siem-indicators` or `add/lab-threat-hunt`.
3. Make focused changes with clear commit messages.
4. Open a PR with:
   - What changed
   - Why it changed
   - Which objective(s) it supports
5. Address review comments and update as needed.

---

## Reporting Issues

If you find an issue but cannot submit a fix, open an issue with:

- File name and section
- What is incorrect or unclear
- Suggested correction (with source when available)

---

Thank you for helping students build real security skills.
