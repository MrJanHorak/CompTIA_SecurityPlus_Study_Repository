# Cheat Sheet: Incident Response Quick Reference

## NIST Lifecycle

1. Preparation
2. Detection and Analysis
3. Containment
4. Eradication and Recovery
5. Lessons Learned

## First 15 Minutes Checklist

- Validate incident and severity
- Start incident ticket and timeline log
- Preserve critical evidence
- Isolate affected systems when needed
- Notify required stakeholders

## Common Evidence Sources

- SIEM alerts and correlated events
- Endpoint telemetry and process trees
- Firewall, proxy, and DNS logs
- Email headers and attachment hashes

## Post-Incident Outputs

- Root cause summary
- Control gap analysis
- Action items with owners and deadlines
