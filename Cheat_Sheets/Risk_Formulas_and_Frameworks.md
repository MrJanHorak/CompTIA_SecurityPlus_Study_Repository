# Cheat Sheet: Risk Formulas and Frameworks

## Quantitative Risk Formulas

- SLE = Asset Value x Exposure Factor
- ALE = SLE x ARO

Where:

- Asset Value (AV): Monetary value of asset
- Exposure Factor (EF): Percent loss from one event
- Annualized Rate of Occurrence (ARO): Expected frequency per year

## Quick Example

- AV = $100,000
- EF = 0.25
- ARO = 0.4

SLE = 100,000 x 0.25 = $25,000
ALE = 25,000 x 0.4 = $10,000
